# Playwright Tests – Practice Software Testing

## Technologies

* JavaScript
* TypeScript
* Node.js
* Playwright


## Installation
```bash
npm install
npx playwright install
```

## Run tests
```bash
npx playwright test
```

Run tests with browser UI:

```bash
npx playwright test --headed
```

## Test example
The project includes a **login test** that:

* opens login page
* enters email and password
* submits the form
* verifies successful login
